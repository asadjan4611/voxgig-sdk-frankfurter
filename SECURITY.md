# Security Policy

## Reporting a vulnerability

Please report security issues privately to Muhammad Asad (https://github.com/asadjan4611).

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/asadjan4611/voxgig-sdk-frankfurter/issues

## Scope

This policy applies to the generated Muhammad Asad SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the Frankfurter public API, generated by
Muhammad Asad. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
